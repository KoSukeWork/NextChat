# Claude Code CLI 插件

Claude Code 请求插件 4.0.0 使用已安装的 Claude Code 的非交互式 `-p / --print`。在设置 → **请求扩展插件** 中点击 **Claude Code 请求插件 → 添加插件**，确认信任提示。在 Anthropic 接口中填写网关地址、API Key、手动添加模型，再选择 Claude Code 4.0.0。

## 桌面内置

选择 **内置（桌面）**。桌面自动查找已安装的 `claude.exe`，也可在接口配置中选择绝对路径的程序；界面显示检测到的版本。使用安装的版本，程序文件更新后自动重新检测。NextChat 按请求启动和结束 CLI，无需另装 Node 或启动桥接服务。

**预先允许的 CLI 工具**是以逗号分隔的名称，默认 `Read,Glob,Grep`，留空禁用本地工具。列出的工具可以执行而不再逐次确认；这些设置为桌面 CLI 接口共享。请求时限以分钟设置，0 为不限，仍可手动取消。

## 外部桥接

网页版选择 **外部桥接服务**，填写桥接地址、令牌和实际 CLI 版本。桌面也可选择外部桥接。网页由 NextChat 服务器访问桥接地址。部署及配置见 [Node 桥接](request-plugins-legacy.md)。

## 会话和工具

系统提示词通过每次请求的临时文件传给 CLI，请求结束时清理。会话历史和配置一致时续接；上下文改变、失败或取消后使用新会话。每个运行中的实例最多保留 100 个闲置会话，七天未使用的会话会被清理。会话隔离在 NextChat 数据目录，不使用用户原有的 Claude 配置。

CLI 本地工具遵循上述预授权名单。当前对话启用的 NextChat MCP 和工具插件也可供 CLI 使用，由 NextChat 原有执行器处理；每次请求只开放该请求启用的工具。CLI 工具事件和分段文字在对话中显示。
