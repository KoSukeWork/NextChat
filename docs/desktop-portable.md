# NextChat Windows x64 便携版

完整解压 ZIP 后，双击 **NextChat.exe**。不需要逐个运行其他文件，也不需要打开终端。

- `NextChat.exe`：软件入口。
- `plugins/nextchat.claude-code/nextchat-wire-relay.exe`：此插件的运行组件，由软件自动调用，支持 HTTP 与 CLI 两种模式。

解压后只保留入口和按插件 ID 分类的运行目录：

```text
NextChat.exe
plugins/
  nextchat.claude-code/
    nextchat-wire-relay.exe
```

源码、构建脚本、开发文档和重复的请求插件 JSON 不随包附送；内置请求插件仍可在界面中直接添加。开源许可内嵌在软件中，可在 **设置 → 开源许可** 离线查看。构建信息位于 `release` 中与压缩包同名的 `_build-info.json`，不放进使用目录。

升级便携版时，完整解压到新文件夹再运行，无需把旧版的 `claude-code-tools` 目录复制过去。

## 在界面里使用 Claude Code 请求插件

1. 打开设置 → **请求扩展插件** → **Claude Code 请求插件** → **添加插件**。这会把请求插件添加到 NextChat；已安装的 Claude Code CLI 可直接使用。
2. 编辑接口，协议选择 **Anthropic Messages**，填写网关地址、API Key，并添加供应商提供的模型名。
3. 请求插件选择 **Claude Code 3.2.0-beta.1**，再选择运行模式。
4. **独立 HTTP 模拟**：保持 **自动管理本地服务**，保存接口即可。软件自动启动所需服务、填写地址和令牌，不需要安装 Claude Code。
5. **真实 CLI（-p）**：保持 **自动管理本地服务**，保存即可。软件自动查找本机已安装的 Claude Code，也可点 **选择程序** 指定 `claude.exe`，选择结果会立即保存；地址、令牌和实际版本由软件维护。尚未安装 CLI 时才需要自行安装，无需另装 Node.js。

**从文件导入其他插件**只用于添加外部或曾从 NextChat 导出的请求插件 JSON 文件。使用上面的 Claude Code 请求插件不需要导入任何文件。

配置只需保存一次。退出 NextChat 时会关闭它启动的服务；重新打开后，按已保存的模式自动启动，可以直接聊天，无需进入设置。请求前会检查服务并刷新连接信息，服务意外退出后也会在下次请求时重新启动。

切换模式并保存后，已无接口使用的旧服务会自动停止；正在生成的回复完成或取消后才释放旧服务。多个接口共用对应模式的服务，只有不同接口确实需要两种模式，或旧请求尚未结束时，才会同时运行两个服务。手动点击 **停止服务** 只是暂停，下次请求会重新启动；需要停用时改为标准 API、禁用插件或删除接口。

自建或远端服务请选择 **连接外部服务**，填写其地址和令牌，服务的启停由你管理。旧版界面自动生成的本机连接会兼容为自动管理；固定端口的手动连接和远端连接继续按外部服务处理。

旧插件不会自动升级，已有接口需要手动选择 3.2.0-beta.1 才能显示管理按钮。更详细的模式、配置和网页部署说明保留在仓库的 [模式说明](claude-code-modes.md) 中。

“便携版”表示免安装启动；聊天、设置和 CLI 会话仍存储在 Windows 用户数据目录中，不是全部保存在解压目录。迁移聊天和配置请使用软件的本地备份功能。
